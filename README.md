# Sunday Badminton

เว็บแอปจัดก๊วนแบดมินตัน: จับฉลากจับคู่ จัดสนาม จดคะแนนสด และเก็บสถิติสะสม
เว็บจริง: https://netkn.github.io/sundaybadminton/

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/app.html` | ต้นฉบับของแอป (หน้าตา ตรรกะ และสไตล์ทั้งหมดอยู่ในไฟล์เดียว) |
| `build.py` | ต่อชั้นข้อมูล Supabase ระบบรหัสก๊วน และส่วนเสริมของเว็บจริงเข้ากับต้นฉบับ แล้วสร้าง `index.html` |
| `index.html` | ไฟล์ที่ GitHub Pages เสิร์ฟจริง **ห้ามแก้ตรง ๆ** ให้แก้ `src/app.html` หรือ `build.py` แล้ว build ใหม่ |
| `icon.png` | ไอคอนตอนเพิ่มลงหน้า home บน iPhone |

## แก้แอปแล้วขึ้นเว็บ

```bash
python3 build.py          # สร้าง index.html ใหม่
node --check /tmp/site.js # ตรวจว่า JavaScript ไม่มี syntax error
git add -A && git commit -m "..." && git push
```

GitHub Pages อัปเดตเองภายใน 1–2 นาที เครื่องที่เปิดแอปอยู่จะโหลดเวอร์ชันใหม่เองเมื่อรีเฟรช

## ข้อมูล

ข้อมูลเก็บที่ Supabase (ตาราง `bd_docs`) การเขียนทั้งหมดผ่านฟังก์ชันฝั่งเซิร์ฟเวอร์ (`bd_*`)
การแก้ไขหรือลบข้อมูลเก่าต้องใช้รหัสก๊วน ซึ่งเก็บแบบเข้ารหัสอยู่ฝั่งเซิร์ฟเวอร์ ไม่อยู่ใน repo นี้
